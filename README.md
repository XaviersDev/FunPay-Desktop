# FunPay Tools для Windows

Мессенджер для чатов FunPay. Rust + Slint.

## Что умеет

- Вход тремя способами, как в мобильном приложении:
  - через браузер (по умолчанию): страница входа FunPay открывается прямо в окне приложения, после входа куки забираются сами;
  - golden_key вручную;
  - файл резервной копии из приложения (`.json`, берётся ключ активного аккаунта).
  Ключ и куки хранятся только в `%APPDATA%\FunPayTools\desktop.json`.
  Ключ можно вставить из буфера: Ctrl+V или кнопка в поле. Вставку читает само приложение, без буфера Slint.
- Встроенный браузер (WebView2). Вход идёт во весь экран. Ссылки funpay.com, когда вы уже вошли, открываются в мини-окне со вкладками поверх чата: его можно перетаскивать за шапку, развернуть, свернуть в плашку снизу (как в мобильном приложении) и закрыть. Все вкладки под вашим аккаунтом. Данные браузера лежат в `%APPDATA%\FunPayTools\WebView2`. Если WebView2 в системе нет, приложение это определяет и на экране входа подсказывает войти по ключу.
- Сделки: продажи и покупки с фильтром по статусу (оплачен, закрыт, возврат) и финансы (операции, баланс, сумма в заморозке). Клик открывает заказ. Разбор как в мобильном приложении (`src/money.rs`).
- Описания профилей с сервера FunPay Tools (общие с расширением и приложением): текст и баннер в профиле и в карточке собеседника. Своё описание правится в профиле. В первый раз аккаунт подтверждается временным лотом «FPT Verify» (создаётся и сразу удаляется), дальше сессия хранится в `desktop.json` (`src/desc.rs`).
- Темы Telegram: .tdesktop-theme (с обоями), .tdesktop-palette и .attheme с телефона (с картинкой WPS). Цвета раскладываются по палитре приложения, недостающие выводятся из основных (`src/tgtheme.rs`). Сброс выбором обычной темы в настройках.
- Несколько аккаунтов: список в настройках и по правому клику на свою аватарку слева, «Добавить аккаунт» с возвратом назад, выход из одного переключает на следующий. Ключи и куки всех аккаунтов только в `desktop.json` на этом ПК.
- Папки слева: Все чаты, Личные, Непрочитанные, Общие, Архив и свои папки. Кнопка со стрелками FunPay рядом с поиском открывает сайт в мини-окне.
- Контекстное меню чата: закрепить, прочитано, без звука, в папку, в архив, открыть на FunPay. Всё хранится локально.
- Копирование и вставка идут через своё обращение к буферу Windows: Ctrl+A, Ctrl+C, Ctrl+X, Ctrl+V в сообщениях, поле ввода и диалогах (и на русской раскладке). Меню по правой кнопке копирует выделенный фрагмент, если он есть.
- Меню открываются у курсора и появляются плавно, окна и настройки тоже.
- Переписка: выделение текста прямо в пузыре, меню по правой кнопке (ответить, копировать, закрепить, картинка, заказ, профиль), ответы в формате приложения `╭─ ⤸ цитата / ╰ текст` с переходом к исходному сообщению, закреплённое сообщение сверху.
- Альбомы картинок (`src/album.rs`), просмотрщик листает весь альбом стрелками.
- Окно отправки фото с превью и подписью: скрепка или Ctrl+V.
- Стикеры из паков приложения. Берутся с нескольких зеркал GitHub/CDN по очереди (jsDelivr, githack, raw), чтобы открывались и на сетях, где GitHub raw заблокирован. Отправка как в мобильном: PNG 512px через file/addChatImage, пауза между картинками.
- Журнал ошибок `%APPDATA%\FunPayTools\log.txt` (кнопка в настройках): что ответил FunPay, если что-то не ушло. Ключи, куки и токены вырезаются.
- Карточка собеседника по клику на имя, экраны профиля (лоты, отзывы) и заказа. В заказе отзыв и ответ правятся и удаляются ссылками прямо в карточке, основные действия одной строкой. На своей странице отзывы ведут к заказам.
- Шрифт Onest дополнен символами, которых нет в шрифтах Windows: ⸨ ⸩, «стилизованные» буквы 𝙌𝙐𝙄𝘾𝙆𝙇𝙔, ᴀʙᴄ, ⓐ ⑴ и т.д. (`tools/merge_fonts.py`, источники DejaVu, FreeSans, DejaVu Math). Цветные эмодзи рисует системный шрифт.
- Уведомления: свои окна в углу экрана (угол, сколько сразу, значок со стрелками FunPay, имя, текст, показ при открытом окне) или обычные уведомления Windows. Клик открывает нужный чат. «Звуковые уведомления» работают отдельно: звук есть, даже если всплывающие выключены (`src/popup.rs`, `ui/notify.slint`).
- Шаблоны: кнопки над полем, под полем, полосой сверху или снизу, либо меню у стикеров (в узком окне всегда меню). Форма, размер, заливка, выравнивание, на всю ширину, компактно, ЗАГЛАВНЫЕ, превью при наведении, свой цвет и картинка у каждого. Переменные как в приложении ($username, $welcome, $lot_name, $order_id, $order_link...) и как в расширении ({buyername}, {lotname}, {welcome}). Бинды Alt+1…9, команда «/название» в поле (Tab подставляет). Команды автоответа: покупатель пишет команду, ответ уходит сам (`src/templates.rs`, `src/feat.rs`, `ui/templates.slint`).
- Переписать с ИИ: правый клик по кнопке отправки, тот же сервер и промпт, что в мобильном приложении (`src/ai.rs`). Подсказка над кнопкой через 1,67 с.
- Кликабельные ссылки в сообщениях (в том числе адреса без http), выделение и копирование при этом работают.
- Цветные ники донатеров как в приложении: градиент, свечение, пульс, волна, глитч, частицы (`src/epic.rs`, `ui/epic.slint`). В настройках «Сделать ник цветным» ведёт к боту.
- Кэш чатов (`%APPDATA%\FunPayTools\chatcache`): список и переписка видны сразу при запуске, свежие данные подгружаются следом (`src/cache.rs`).
- Обновления сами с GitHub Releases (`src/update.rs`), см. ниже.
- Работа в фоне: крестик прячет окно в трей, опрос и уведомления продолжаются. Значок в трее: щелчок открывает окно, в меню «Выход». Автозапуск с Windows (`HKCU\...\Run`, флаг `--background`, сразу в трее). Второй запуск программы просто показывает уже открытое окно (`src/tray.rs`). Оба поведения выключаются в настройках.
- Время в сообщении: если задержать курсор на нём на 1,67 с, показываются секунды.
- Тонкая своя шапка окна без иконки и названия.
- Метка FunPay Tools всегда включена (`src/fpt.rs`).

## Как выпускать обновления

Репозиторий: `XaviersDev/FunPay-Desktop`. Приложение раз в 4 часа (и через 15 секунд после запуска) смотрит `releases/latest`.

1. Поднять версию в `Cargo.toml` и `assets/app.rc`.
2. Создать релиз с тегом `v4.4.0` (или `4.4.0`) и приложить файл `FunPayTools.exe`. Подойдёт и zip, внутри которого есть `FunPayTools.exe` (ищется ассет с `win` в имени, исходники `src` пропускаются).
3. Всё. Клиенты скачают файл, сверят sha256 (GitHub считает его сам) и подменят свой exe: старый переименовывается в `.exe.old`, новый встаёт на его место. Если окно спрятано в трей, перезапуск сразу и тихо, если открыто, в настройках появится кнопка «Перезапустить», а ещё перезапуск случится сам, когда окно закроют в трей.

Черновики и версии не выше текущей игнорируются. Пока репозитория нет, в настройках пишется «Новых выпусков пока нет».

## Метка клиента для FunPay

В каждом запросе к funpay.com уходит кука `fpt_client=funpay-tools-desktop`. Имя и значение в одном месте: `CLIENT_COOKIE` в `src/fp.rs`.

## Сборка

Нужен свежий Rust (собрано на 1.97).

На Windows:
```
cargo build --release
```
Готовый файл: `target\release\funpay-tools-desktop.exe`.

С Linux под Windows (так собран приложенный exe):
```
rustup target add x86_64-pc-windows-gnu
sudo apt install mingw-w64
cargo build --release --target x86_64-pc-windows-gnu
```

## Устройство

| Файл | Что внутри |
|---|---|
| `src/fp.rs` | Сеть FunPay: куки, повтор при 428, runner, история, отправка, профиль, отзывы, заказы |
| `src/parse.rs` | Разбор HTML/JSON: чаты, сообщения, профиль, заказ, ответы, превью |
| `src/worker.rs` | Фоновый поток: вход, опрос, уведомления, чат FunPay Tools |
| `src/ui.rs` | Состояние интерфейса, папки, меню, экраны |
| `src/browser.rs` | Встроенный браузер на WebView2 (wry) |
| `src/stickers.rs` | Паки стикеров, зеркала и кэш |
| `src/money.rs` | Продажи, покупки, финансы |
| `src/desc.rs` | Сервер описаний профилей |
| `src/tgtheme.rs` | Импорт тем Telegram |
| `src/log.rs` | Журнал ошибок без секретов |
| `src/browser.rs` (fn available) | Проверка WebView2 в реестре (EdgeUpdate) |
| `src/album.rs` | Склейка картинок в альбомы |
| `src/sys.rs` | Уведомления, звук, тема системы |
| `src/popup.rs` | Свои всплывающие уведомления |
| `src/templates.rs` | Шаблоны, переменные, команды автоответа |
| `src/feat.rs` | Связка шаблонов, ИИ, ников, уведомлений, кэша и обновлений с интерфейсом |
| `src/ai.rs` | Переписать с ИИ |
| `src/epic.rs` | Цветные ники |
| `src/cache.rs` | Кэш чатов и переписки |
| `src/update.rs` | Обновления с GitHub |
| `ui/*.slint` | Весь интерфейс |
| `patches/i-slint-backend-winit-*` | Исправление деления на ноль при частоте монитора 0 Гц |
| `patches/webview2-com-sys-*` | WebView2Loader.dll грузится в рантайме: exe запускается и без неё, сама dll вшита в exe и распаковывается в `%APPDATA%\FunPayTools` |

Встроенному браузеру нужен WebView2 Runtime. В Windows 10/11 он обычно уже стоит, если нет, ставится с сайта Microsoft.

## Для разработки

- `FPT_DEMO=main` (`settings`, `common`, `login`, `login2`, `login3`, `profile`, `reviews`, `order`, `card`, `sendbox`, `reply`, `deals`, `finance`, `mydesc`, `descedit`, `mini`, `minibar`, `tgtheme` с `FPT_THEME_FILE=путь`) запускает с демо-данными без входа.
- `FPT_SHOT=out.png:1180x760:main[:dark]` рисует скриншот без окна.
- `FPT_SHADOW=1` включает системную тень Windows у окна без рамки.
- `cargo test` проверяет парсеры, метку, альбомы. `cargo test live_ -- --ignored` ходит в настоящий FunPay без входа.
